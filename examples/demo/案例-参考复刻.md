# 案例：I 路线参考复刻实战 — 护肤品参考片拆解与变体量产（2026-11-01）

I 路线（纯方法，不装平台）首支验证：拿一条 Pexels 护肤品实拍参考片，复刻出两支换品变体 + 一支对比片。本地存档：video-studio/tests/2026-11-01/remake-demo/（结构卡、两支变体、复刻对比_参考vs变体.mp4 29.6s）。

## 方法四步

1. **拆结构卡**：逐镜拆参考片——每镜的时长、景别、主体动作、镜头运动、光线、屏上文字，写成功能表（这镜在片子里干什么），存为 `结构卡.md`。拆的是**结构**，不是画面像素。
2. **列变量表**：把可替换项显式列出——产品（面霜→男士面霜 / 唇膏）、场景（浴室台面→梳妆台）、模特、色调；不可变的（节奏、镜序、每镜功能）锁死。
3. **按卡生成**：每个变体逐镜用 E 路线原生生成，提示词 = 结构卡该镜的功能描述 + 变量表取值；角色/产品需要一致性时先用图片生成出锚图再图生视频。
4. **拼对比片验收**：参考 vs 变体同屏对比，逐镜核对功能是否对位（时长、动作、镜头感），不对位的单镜重生，不整片重做。

## 经验

- 复刻的粒度是「镜的功能」：参考片第 3 镜是"质地特写"，变体就必须也是质地特写，换的只是哪款产品的质地。
- 变量表先行能避免生成时随手改设定——两支变体共用一张结构卡，只换变量表，产出稳定。
- 这条路线适合：用户给一条喜欢的片子说"照这个感觉再做一条（换我的产品）"。要换脸级精确复刻或百条级量产时，方法不够用，需另行评估独立工具（总控技能「不要做的事」里有说明）。
