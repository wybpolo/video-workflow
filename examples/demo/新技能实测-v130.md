# 新技能实测速记（v1.3.0 四技能，2026-11-01 逐个实渲验证）

四条示例片的本地存档在 video-studio/tests/2026-11-01/eval2-demos/<技能名>/，每个目录有 README 记录命令与数据。这里只记上手要点和坑，细节以各技能 SKILL.md 原文为准。

## ffmpeg-skill（F 路线工具层）

- 标准姿势：`probe.py` 先行 → 目标 script 带 `--dry-run` 出 JSON 计划 → 确认后执行 → `check.py --platform <tiktok|reels|...>` 验收。实测：截《凌晨两点的花》v2 的 15s 段做两遍 loudnorm 到 −14.02 LUFS / −1.14 dBTP,TikTok 验收 14 项全过。
- 坑 1：**无损截取是包（packet）精度**：请求 15.0s 实出 15.13s，起点不吸附关键帧。要帧精确加 `--accurate`（重编码）。
- 坑 2:loudness 的 `--dry-run` **也会真跑第一遍测量**，计划里的 LUFS 是实测值不是估算——正好用来排产。
- 坑 3:check.py 的 JSON 里 `verified: false` **不是验收失败**：verified 只对写文件工具定义，check 是测量工具；判据是 failed=0 + exit 0。只看 JSON 不读它的 contract 文档会误判。

## pixelfx（像素特效资产层）

- 在它的 checkout 内跑：`node tools/render.mjs <类别>/<特效名> --mp4`，零 npm 依赖一次跑通；244 个特效（火/爆炸/魔法/天气/转场 wipe 等），还能导 sprite sheet。
- 坑：各特效**原生画幅不一**（竖的横的都有），拼展示/合成时统一 fps + `flags=neighbor` 缩放（保像素锐利）+ 黑边 pad;`weather/rain` 的 mp4 实际含 3 个循环共 24s，只取需要的段。渲染产物按其设计写进 checkout 的 `records/`，成片记得拷回项目目录。

## manimgx（C 路线数学/3D 引擎）

- 装引擎：`uv tool install --python 3.14 manimgx`（0.1.1;ManimCE 兼容 API，scene 基本一次写成）。公式走内置 Typst 排版，**不需要系统 LaTeX**;CJK 字体包自带，中文标题直接渲。
- **本 VM 无 GPU 可用**:wheel 自带 lavapipe（CPU Vulkan 软渲染），进程内存映射实锤在跑；720p 数学片引擎渲染比实时还快（14.9s 片用 22.5s）。实测片：《傅里叶级数逼近方波》——LaTeX 公式 + 部分和曲线逐级贴合，这类精度题材才值得动它，简单图解仍走 anatomy/huashu。
- 坑：**静止段（wait）存成单帧长时长帧**，帧数 ≠ 时长 ×fps;ffmpeg 按时间 `-ss` 抽尾部帧会抽空，抽帧要用帧号 select。

## vibe-knowledge-film（A 路线无旁白知识长片子路线）

- 严格走它 SKILL.md 的 0–9 步：事实表 → 找形象（把概念"演"出来）→ 文案与分镜同表 → 选外观（B 寓言 / C 夜曲）→ 先做最难的镜 → 先出 30 秒样片过关 → 全合成事件音（无旁白无配乐）→ 量化终检。实测样片 《为什么冰会浮》33s、1080p、−18.37 LUFS（正对 C 世界规格）。
- 坑 1（字体）：别改引擎代码——把本地字体**符号链接进它预留的 `engine/fonts/` 槽位**（get_fonts.py 的下载目标），再跑 `get_fonts.py --check` 验"齐全"。本机顶替：中文 Noto Serif/Sans CJK，西文 Liberation Serif 代 Cormorant/Lora,Mono 用 DejaVu Sans Mono。
- 坑 2（浏览器）：render.py 用 `channel="chrome"` 启动，本机没装 Chrome——把 Playwright 缓存的 Chromium 链到 `/opt/google/chrome/chrome` 解决，引擎零修改。Python 侧 playwright 装进工程内 `.venv`。
- 坑 3（慢）：VM CPU 逐帧渲染，33s 片约 16 分钟，要有预期；它文档里的 3–6 fps 在本机达不到。
- 约定：样片阶段可按其自带样例先例省片名卡与片尾文献屏；画面里示意性夸张（如分子占地增幅）必须在屏上小字标注"示意"，真实数字只走读数/字幕。
