# 案例：PPT 转视频实战 — 比亚迪 T5 使用教程（2026-10-31）

首支真实生产。输入：用户给的 44 页产品手册 PPT（PDF）。产出：4 分 30 秒、1920×1080@30 教程片（原生 TTS 旁白 + 烧录字幕 + 旁挂 SRT）。路线：B（HyperFrames）。用户评价：很好。本地存档：成片在 video-studio/archive/比亚迪T5使用教程/，可再生工程在 video-studio/projects/byd-t5-tutorial（gen.py 一键重出 HTML/计划/字幕）。

## 流程（已固化进总控技能「PPT / 文档转视频」一节，这里记实战细节）

1. **双路拆解 PPT**：PyMuPDF 同时取文本层和逐页渲染图，拼 contact sheet 选材——哪些页有真图/真数据、哪些只是排版，一眼可辨，避免只读文本层漏掉图里的信息。
2. **关键数字多源核对**：手册数字与公开来源交叉验证（T5DM 55.39kWh / 纯电 150km / 综合 1100km+；T5EV 82–132kWh；2C 快充 30→80% ≈18 分钟）。
3. **先配音、后定时**：每场时长 = 0.4s 头垫 + 旁白实测时长 + 0.9s 尾垫；10 场旁白拼起来与总时长计划分毫不差（270.5s)。
4. **字幕按句比例切分**：44 条 cue 按句长比例对齐旁白时间轴，烧录（Noto Sans CJK SC)+ 旁挂 .srt 双交付。
5. **版式红线**：画面内容收在 y≈920 以上（字幕安全区）；大数字加 nowrap 防折行；长场用双相位（前半讲、后半演）防静止。

## 踩过的坑

- **长片渲染 exit 0 也可能是坏文件**：270s 渲染曾进程正常退出但 MP4 被截断（有 mdat 无 moov)。**渲染后必须 ffprobe 验时长/moov 才算成功**；失败就清掉 work-* 与 .hf-transaction-* 残留目录重渲，不要在残缺文件上续。
- **CJK 字体必须本地 @font-face**：CSS 只写字体名，HyperFrames check 会 error、渲染还会回退默认字体。本机做法：fonttools 从 Noto Sans CJK TTC 取 SC 面转 woff2 放项目 assets/fonts/（转换约 3 分钟，后台跑）。
- **不确定的数字不要默改**：成片里两处数字与 PPT 对不上——综合续航 1100km（PPT 没写，来自公开来源）、快充 18 分钟（公开来源口径；PPT 对照表是 20/38 分钟）。处理方式是**交付时主动向用户标注出入、请其拍板**，事后查证（Bitauto：综合续航可达 1100km、实测满油满电 1138km;≤100kWh 的 2C 快充 30→80% 为 15–18 分钟）确认可保留。教训：有出入先标注，不自作主张改稿，也不闷头照抄。
