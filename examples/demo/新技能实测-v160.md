## 验证（同一把尺子：kazi_check 卡字率）

- **基线**：《汽车技法样片 v2.2》（v1.5.0 流程产物）抽 8 个关键词：卡字率 **0%**，随机基线 13%，lift **−13%**。失败与规范三因吻合：静帧、匀速运动、动作与词错位（绞盘高亮早约 0.6s）。
- **演示**：《绞盘自救》（HyperFrames，32.2s，965 帧，5 个关键词按规范落点 + 大字卡独立事件）：卡字率 **80%**（4/5），lift **+55%**；verify_video technical_pass。唯一未命中「回收」：落点面积过小且前一秒基底动量高——小落点需加大动作或保证前置静默。
- 演示的已知偏差（项目 README 全文）：旁白 70% 语速 + @gap 留白凑时长；响度靠限幅补增益达标；未做正常速度通看/通听。附带发现：基线片第 2 段旁白（3–11s）转写整段缺失，疑被原生声床压没，仅记录未处理。
